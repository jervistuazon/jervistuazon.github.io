FORESTVILLE export package

Files:
- ../FORESTVILLE.html: standalone presentation page with inline CSS and JavaScript, linked to assets/.
- ../START-HERE.txt: quick extraction and opening instructions.
- project.json: editable webtool source project with matching assets/... links (stored inside assets/).
- assets/: collected image and video files required by the presentation.

Extract the full folder before opening FORESTVILLE.html so the relative assets/ links resolve correctly.
No remote media dependencies were found in this project.

Font dependencies:
- Bundled Cormorant Garamond and Inter font faces are included under assets/fonts/.
All presentation font faces used by this package are bundled local assets.
