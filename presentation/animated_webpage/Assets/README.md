# Section Assets

Place section-specific images, videos, audio, textures, or data files in the folder that matches the section ID in `index.html`.

- `scene-1/` maps to `<section id="scene-1">`
- `scene-2/` maps to `<section id="scene-2">`
- `scene-3/` maps to `<section id="scene-3">`
- `scene-4/` maps to `<section id="scene-4">`

Use paths such as `Assets/scene-1/example.png` when referencing assets from HTML, CSS, or JavaScript.
