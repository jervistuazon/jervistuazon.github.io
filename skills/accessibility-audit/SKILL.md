# Accessibility Audit

## Use When
- Running accessibility review tasks.
- Hardening UX for keyboard and assistive technology users.

## Audit Checklist
- Heading order and landmark semantics.
- Keyboard reachability and focus visibility.
- Color contrast for text/UI states.
- Alternative text and media accessibility.
- Reduced-motion behavior for animation-heavy sections.

## Workflow
1. Inspect markup and interaction patterns.
2. List issues by severity.
3. Provide concrete remediation steps.
4. Implement fixes only when requested.

## Verification
- Confirm each issue maps to a specific file and selector/component.
